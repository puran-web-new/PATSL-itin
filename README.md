# 🏢 PATSL ITIN Management System\n\nEnterprise-grade full-stack ITIN application management system built with Next.js 14, Supabase, Neon, PostgreSQL, and Vercel.\n\n## 📋 Overview\n\nPATSL ITIN Management System is a complete solution for managing IRS ITIN applications with:\n- **Client Application Form** - Professional intake form\n- **Admin Portal** - Complete management dashboard\n- **Client Portal** - Real-time application tracking\n- **Real-time Notifications** - Email & WhatsApp updates\n- **Multi-database Architecture** - Supabase, Neon, PostgreSQL\n- **Serverless Deployment** - Vercel ready\n\n## 🚀 Quick Start\n\n### Prerequisites\n- Node.js 18+\n- npm or yarn\n- Git\n\n### Installation\n\n1. **Clone the repository**\n```bash\ngit clone https://github.com/puran-git-for-web/PATSL-itin.git\ncd PATSL-itin\n```\n\n2. **Install dependencies**\n```bash\nnpm install\n```\n\n3. **Setup environment variables**\n```bash\ncp .env.local.example .env.local\n```\n\nFill in your credentials:\n```env\n# Supabase\nNEXT_PUBLIC_SUPABASE_URL=your_supabase_url\nNEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key\nSUPABASE_SERVICE_ROLE_KEY=your_service_role_key\n\n# Neon\nNEON_DATABASE_URL=postgresql://user:password@host/dbname\n\n# PostgreSQL\nPOSTGRES_URL=postgresql://user:password@host/dbname\n\n# JWT\nJWT_SECRET=your_jwt_secret_min_32_chars\n\n# Email\nEMAIL_HOST=smtp.gmail.com\nEMAIL_PORT=587\nEMAIL_USER=your_email@gmail.com\nEMAIL_PASSWORD=your_app_password\nEMAIL_FROM=noreply@puranaccounting.com\n\n# Twilio\nTWILIO_ACCOUNT_SID=your_account_sid\nTWILIO_AUTH_TOKEN=your_auth_token\nTWILIO_WHATSAPP_NUMBER=whatsapp:+1234567890\n\n# Admin\nADMIN_EMAIL=Ramratan@PuranAccounting.com\n\n# App\nNEXT_PUBLIC_APP_NAME=\"Puran Accounting & Tax Solution Lab\"\nNEXT_PUBLIC_APP_URL=https://itin.patsl.org\nNODE_ENV=development\n```\n\n4. **Setup Supabase Database**\n```bash\n# Create tables using SQL migrations\n# See db/migrations/schema.sql\n```\n\n5. **Run development server**\n```bash\nnpm run dev\n```\n\nOpen [http://localhost:3000](http://localhost:3000) in your browser.\n\n## 📂 responsive\n- Success confirmation\n\n### 🛠️ Admin Portal\n- Secure JWT authentication\n- Dashboard with KPIs\n- Submissions list with filters\n- Detailed submission view\n- Edit capabilities\n- Status management\n- Internal notes system\n- Real-time updates\n\n### 👤 Client Portal\n- Login and registration\n- Application tracking\n- Real-time status updates\n- Document management\n- Profile settings\n\n### 🔔 Notifications\n- Email on submission\n- Email on status change\n- WhatsApp messages via Twilio\n- Notification logs\n\n### 🗄️ Multi-Database Support\n- **Supabase** - Primary limiting ready\n- Secure cookie handling\n\n## 🚢 Deployment\n\n### Deploy to Vercel\n\n1. **Push to GitHub**\n```bash\ngit add .\ngit commit -m \"Initial commit\"\ngit push origin main\n```\n\n2. **Connect to Vercel**\n   - Go to https://vercel.com/dashboard\n   - Click \"New Project\"\n   - Import GitHub repository\n   - Add environment variables\n   - Click Deploy\n\n3. **Add Custom Domain**\n   - Go to project settings\n   - Navigate to \"Domains\"\n   - Add your domain (e.g., itin.patsl.org)\n   - Update DNS records\n\n## 📡 API Endpoints\n\n### Applications\n- `POST /api/applications` - Submit application\n- `GET /api/applications` - List applications (admin)\n- `GET /api/applications/[id]` - Get single application\n- `PUT /api/applications/[id]` - Update application\n- `POST /api/applications/[id]/status` - Change status\n- `POST /api/applications/[id]/notes` - Add notes\n\n### Authentication\n- `POST /api/auth/admin-login` - Admin login\n- `POST /api/auth/admin-logout` - Admin logout\n- `POST /api/auth/client-login` - Client login\n- `POST /api/auth/client-register` - Client register\n\n### Notifications\n- `POST /api/notifications/email` - Send email\n- `POST /api/notifications/whatsapp` - Send WhatsApp\n\n### Dashboard\n- `GET /api/dashboard/stats` - Get KPIs\n- `GET /api/dashboard/activity` - Get activity feed\n\n## 📊 Database Schema\n\n### Applications Table\n```sql\nCREATE TABLE applications (\n  id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),\n  full_name VARCHAR(255) NOT NULL,\n  email VARCHAR(255) NOT NULL,\n  phone VARCHAR(20) NOT NULL,\n  date_of_birth DATE NOT NULL,\n  country_of_origin VARCHAR(100),\n  us_address TEXT NOT NULL,\n  reason_for_itin TEXT,\n  contact_method VARCHAR(20),\n  status VARCHAR(50) DEFAULT 'pending',\n  created_at TIMESTAMP DEFAULT NOW(),\n  updated_at TIMESTAMP DEFAULT NOW(),\n  assigned_to UUID\n);\n```\n\nSee `db/migrations/schema.sql` for complete schema.\n\n## 🛠️
